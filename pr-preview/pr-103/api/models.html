Models & Methods¶

The models subpackage contains quantum circuit templates (ansätze) and analysis tools.

Ansätze: Quantum Circuit Templates¶

Ansätze are pre-built quantum circuit patterns used as templates for quantum algorithms.

Circuit templates to simulate: variational patterns and textbook algorithms.

class mpstab.models.ansatze.Ansatz(nqubits: int)[source]¶

Bases: ABC

Abstract ansatz to generate quantum states.

Every ansatz names the fields that set its two resources, so a sweep knows which knob to turn:

  • magic_parameters: fields that set how far the circuit is from a Clifford circuit, i.e. how many magic gates HSMPO keeps and how large their angles are;

  • entanglement_parameters: fields that set which qubits interact and for how long, i.e. how fast the bond dimension of the state can grow.

A field may appear in both: a generic rotation angle sets the magic and, through the couplings, also the entangling power.

partitionate_circuit(replacement_probability: float = 0.0, replacement_method: str = 'closest')[source]¶

Split the circuit into a Clifford part and the magic gates left over.

Each non-Clifford gate is replaced by the nearest Clifford one with probability replacement_probability, and kept as a magic gate otherwise. Every magic gate is recorded with the number of Clifford gates preceding it, which is where it has to be reinserted later.

Parameters:

  • replacement_probability – chance of replacing each non-Clifford gate. The default 0 keeps every non-Clifford gate as magic.

  • replacement_method – "closest" or "random" Clifford angle.

Returns:

((magic_gates, clifford_circuit), full_circuit), where magic_gates is a list of (breakpoint_index, gate) and full_circuit is the sampled circuit including its magic gates.

class mpstab.models.ansatze.HammingWeightPreserving(nqubits: int, nlayers: int = 1)[source]¶

Bases: Ansatz

Hamming-weight-preserving ansatz built from decomposed RBS gates.

Each RBS gate rotates within the \(\{|01\rangle, |10\rangle\}\) subspace of a qubit pair, leaving \(|00\rangle\) and \(|11\rangle\) unchanged:

RBS(θ)|01⟩ =  cos(θ)|01⟩ + sin(θ)|10⟩
RBS(θ)|10⟩ = -sin(θ)|01⟩ + cos(θ)|10⟩

RBS is decomposed into gates mpstab supports natively:

CNOT(ctrl=q1, tgt=q0)
RY(q1,  θ)              ← magic gate
CNOT(ctrl=q0, tgt=q1)
RY(q1, -θ)              ← magic gate
CNOT(ctrl=q0, tgt=q1)
CNOT(ctrl=q1, tgt=q0)

The circuit always starts with n//2 X gates to prepare the half-filling state \(|1\dots10\dots0\rangle\), giving a fixed Hamming weight of n//2.

Within each layer the connectivity pattern mirrors hw_preserving from Qibo examples: four connect_qubits passes with jump sizes 1 and 2 and different starting offsets to explore both nearest- and next-nearest- neighbour correlations with circular boundary conditions.

Parameters:

  • nqubits – Number of qubits (must be even).

  • nlayers – Number of RBS layers.

class mpstab.models.ansatze.KickedIsing(nqubits: int, n_steps: int = 1, theta_h: float = 0.8, theta_z: float = 0.0, theta_j: float = -1.5707963267948966)[source]¶

Bases: _KickedIsingBase

Build a kicked Ising circuit on an open chain.

Each of the n_steps steps applies the kicks \(R_X(\theta_h)\) and then \(R_Z(\theta_z)\) on every qubit, followed by the couplings \(R_{ZZ}(\theta_J)\) on the even bonds and then on the odd bonds. Every coupling is written as CNOT · RZ(theta_j) · CNOT, the form HSMPO splits into Clifford and magic gates, so the circuit needs no transpilation. At the default theta_j = -pi/2 the couplings are Clifford and only the kicks are magic, so the MPS bond dimension grows with the number of steps.

Every angle that is not a multiple of \(\pi/2\) is a magic gate as a whole; ParametricKickedIsing separates the Clifford part of each angle from the magic one.

  • theta_z – angle of the longitudinal kicks \(R_Z\).

class mpstab.models.ansatze.ParametricKickedIsing(nqubits: int, n_steps: int = 1, delta_h: float = 0.1, delta_j: float = 0.0, delta_z: float = 0.0, clifford_h: float = 1.5707963267948966, clifford_j: float = -1.5707963267948966)[source]¶

Bases: _KickedIsingBase

Build a kicked Ising circuit parametrised by its distance from a Clifford point.

It is the circuit of KickedIsing with the angles

\[\theta_h = \theta_h^C + \delta_h, \qquad \theta_J = \theta_J^C + \delta_J, \qquad \theta_z = \delta_z, \]

where \(\theta_h^C\) and \(\theta_J^C\) are multiples of \(\pi/2\), so that at \(\delta = 0\) the whole circuit is Clifford. The defaults \(\theta_h^C = \pi/2\), \(\theta_J^C = -\pi/2\) are the self-dual point, where the entanglement grows at the maximal speed.

Every rotation is written as its Clifford part followed by the deviation, \(R(\theta^C + \delta) = R(\delta)\,R(\theta^C)\), as two separate gates. HSMPO then puts \(R(\theta^C)\) in the stabilizer part and keeps only the small rotation \(R(\delta)\) as a magic gate, instead of treating the whole \(R(\theta^C + \delta)\) as magic. The two groups of fields therefore tune the two resources separately:

  • the deviations delta_h, delta_j, delta_z set the magic: the number of magic gates (a deviation equal to zero adds no gate) and the size of their angles;

  • the Clifford skeleton clifford_h, clifford_j and n_steps set the entanglement: which Clifford circuit the stabilizer part evolves, hence how fast the entanglement grows. The deviations change it only perturbatively.

Each of the n_steps steps applies the kicks \(R_X\) and then \(R_Z\) on every qubit, followed by the couplings \(R_{ZZ}\) on the even bonds and then on the odd bonds, each coupling written as CNOT · RZ · CNOT.

Parameters:

  • nqubits – number of qubits in the chain.

  • n_steps – number of kick-and-couple steps.

  • delta_h – deviation of the transverse kicks \(R_X\) from clifford_h.

  • delta_j – deviation of the \(R_{ZZ}\) couplings from clifford_j.

  • delta_z – angle of the longitudinal kicks \(R_Z\) (Clifford point: 0).

  • clifford_h – Clifford angle of the transverse kicks, a multiple of pi/2.

  • clifford_j – Clifford angle of the couplings, a multiple of pi/2.

class mpstab.models.ansatze.RampedKickedIsing(nqubits: int, n_steps: int = 1, delta_h: float = 0.1, delta_j: float = 0.0, delta_z: float = 0.0, clifford_h: float = 1.5707963267948966, clifford_j: float = -1.5707963267948966, delta_h_last: float | None = None, delta_z_last: float | None = None, bond_density: float = 1.0, disorder: float = 0.0, seed: int | None = None)[source]¶

Bases: ParametricKickedIsing

Build a ParametricKickedIsing circuit whose magic changes from step to step.

The deviation of the transverse kicks goes from delta_h at the first step to delta_h_last at the last one, geometrically when the two have the same sign and linearly otherwise; likewise the longitudinal kicks, from delta_z to delta_z_last. With the magic concentrated in the first steps, a head/tail split leaves the large rotations to the head and only small angles to the tail; delta_h < delta_h_last is the opposite profile, as a control. Without delta_h_last and delta_z_last, at bond_density = 1 and disorder = 0, the circuit is exactly ParametricKickedIsing.

Two optional sources of randomness, drawn from numpy.random.RandomState(seed) (from numpy’s global generator when seed is None), in circuit order:

  • disorder > 0 gives every kick its own deviation, \(\delta_h (1 + \mathrm{disorder} \cdot u)\) with \(u\) uniform in \([-1, 1]\), so different seeds are disorder realisations of the same magic profile;

  • bond_density < 1 keeps each coupling of each step with that probability and drops the others. At \(\delta_J = 0\) the couplings are Clifford, so this lowers the entanglement without changing the magic.

No number is drawn when disorder = 0 and bond_density = 1.

The ramp and the disorder add magic knobs to those of ParametricKickedIsing; bond_density adds an entanglement knob.

Parameters:

  • nqubits – number of qubits.

  • n_steps – number of kick-and-couple steps.

  • delta_h – deviation of the transverse kicks at the first step.

  • delta_h_last – deviation of the transverse kicks at the last step (None: delta_h at every step).

  • delta_j – deviation of the \(R_{ZZ}\) couplings from clifford_j.

  • delta_z – angle of the longitudinal kicks at the first step.

  • delta_z_last – angle of the longitudinal kicks at the last step (None: delta_z at every step).

  • clifford_h – Clifford angle of the transverse kicks, a multiple of pi/2.

  • clifford_j – Clifford angle of the couplings, a multiple of pi/2.

Bases: RampedKickedIsing

Build a RampedKickedIsing circuit on a star: a central-spin model.

The kicks are those of RampedKickedIsing; the couplings of each step are \(R_{ZZ}\) between the hub (qubit 0) and every leaf, leaf 1 first, each written as CNOT · RZ · CNOT. The hub is an ordinary logical qubit; the label 0 is a convention. The circuit suits devices with a central element, such as an IQM Star: there the compiler can move the hub’s state into the computational resonator once per step and apply all its CZ gates from it, instead of moving a qubit in and out for nearly every CZ as a chain needs (on a 10-qubit IQM Star, 6 steps: about 20 MOVE gates against about 100 for the chain).

Args: as RampedKickedIsing; bond_density applies to the hub-leaf couplings.

Entanglement Metrics & Analysis¶

Tools for analyzing entanglement and state properties.

State metrics: the stabilizer Renyi entropy, a measure of how much magic a state carries, and the Meyer-Wallach global entanglement.

Only the HSMPO estimators live here. For a dense statevector, Qibo already provides both metrics, qibo.quantum_info.stabilizer_renyi_entropy() and qibo.quantum_info.meyer_wallach_entanglement(), and the estimators follow the same conventions so the two can be compared directly.

mpstab.models.metrics.meyer_wallach_mps(hsmpo: HSMPO) → float[source]¶

Compute the Meyer-Wallach global entanglement of the state an HSMPO represents.

Evaluates the average single-qubit linear entropy

\[Q(\psi) = 2 \left(1 - \frac{1}{n} \sum_{k=0}^{n-1} \mathrm{Tr}\,\rho_k^2\right), \]

with \(\rho_k\) the reduced state of qubit \(k\). The value is 0 for product states and 1 when every qubit is maximally entangled with the rest. For a dense statevector, use qibo.quantum_info.meyer_wallach_entanglement() instead.

The HSMPO state is \(C|\psi_{\mathrm{MPS}}\rangle\), with \(C\) the cached Clifford circuit, so the single-qubit reduced states cannot be read off the MPS sites. The function rebuilds each purity from the qubit’s Bloch vector,

\[\mathrm{Tr}\,\rho_k^2 = \frac{1}{2} \left(1 + \langle X_k\rangle^2 + \langle Y_k\rangle^2 + \langle Z_k\rangle^2\right), \]

which turns \(Q\) into

\[Q = 1 - \frac{1}{n} \sum_{k=0}^{n-1} \sum_{P \in \{X, Y, Z\}} \langle P_k\rangle^2 . \]

It backpropagates every \(\langle P_k\rangle\) through \(C\) and contracts it against the cached MPS. That costs \(3n\) contractions, and the result is exact up to the MPS truncation.

Parameters:

hsmpo – the hybrid stabilizer MPO, with its MPS cache already evolved.

Returns:

The Meyer-Wallach \(Q\) of the circuit’s output state.

mpstab.models.metrics.stabilizer_renyi_entropy_mps(hsmpo: HSMPO, alpha: int = 2, n_samples: int = 1000, seed: int | None = None) → float[source]¶

Estimate the stabilizer Rényi entropy of the state an HSMPO represents.

Samples n_samples Pauli strings \(P_k\) uniformly from the \(4^n\) of them and replaces the exact Pauli sum with its Monte Carlo estimate,

\[M_\alpha \approx \frac{1}{1 - \alpha} \log_2\left(\frac{4^n}{K} \sum_{k=1}^{K} \frac{|\langle P_k\rangle|^{2\alpha}}{2^n}\right), \]

with \(K\) the number of samples. The estimate of the sum is unbiased; its logarithm is not, and the bias shrinks as \(K\) grows. The result is the total \(M_\alpha\) in bits, the convention of qibo.quantum_info.stabilizer_renyi_entropy() with base=2, which gives the exact value for a dense statevector; divide by hsmpo.nqubits for the entropy per qubit. Each \(\langle P_k\rangle\) is backpropagated through the cached Clifford circuit and contracted against the cached MPS, so the MPS is never rebuilt.

Parameters:

  • hsmpo – the hybrid stabilizer MPO, with its MPS cache already evolved.

  • alpha – Rényi order \(\alpha\), an integer of at least 2.

  • n_samples – number of Pauli strings to sample. More samples lower the variance, but with uniform sampling most strings have a vanishing expectation value, so the relative variance grows exponentially with the number of qubits.

  • seed – seed of the random generator, for reproducible samples.

Returns:

The estimated stabilizer Rényi entropy \(M_\alpha\), in bits.

Raises:

ValueError – if alpha is below 2, or if the estimated Pauli sum is not positive.

Available Functions:

  • stabilizer_renyi_entropy_mps(hsmpo, alpha, n_samples, seed): sampled stabilizer Renyi entropy of the state an HSMPO represents

  • meyer_wallach_mps(hsmpo): Meyer-Wallach global entanglement of the state an HSMPO represents

For a dense statevector, use Qibo’s qibo.quantum_info.stabilizer_renyi_entropy and qibo.quantum_info.meyer_wallach_entanglement; the HSMPO versions follow the same conventions.

mpstab.models.utils.replace_non_clifford_gate(gate, replacement_method, candidates=None)[source]¶

Replace a non-Clifford RX/RY/RZ, RXX/RYY/RZZ or GPI2 gate with a Clifford one.

Parameters:

  • gate – the gate to replace.

  • replacement_method – "closest" Clifford angle, or a "random" one.

  • candidates – the Clifford angles to choose from. Defaults to the multiples of pi/2 legal for the gate.
