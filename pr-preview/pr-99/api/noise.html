Noise¶

Stochastic Pauli noise, including correlated multi-qubit terms, coherent Pauli-rotation errors, and general channels such as amplitude damping and thermal relaxation on the HSMPO surrogate; after gates, on the spectators of a gate (crosstalk), on idle qubits, at preparation and at readout.

Describe the noise with a NoiseModel, adding errors rule by rule as in qibo, then call noisy_expectation():

  • add() puts an error after every matching gate, or on the initial state and the measured bits for StatePreparationError and ReadoutError;

  • add_crosstalk() puts it on the qubits coupled to a gate but not acted on by it;

  • add_idle() puts it on the qubits left idle in each moment, or on coupled pairs of them, as an always-on ZZ does.

apply() returns the same noisy circuit as a qibo density-matrix circuit, for exact reference values on small systems.

A Pauli fault pulled into the Clifford frame leaves the tableau unchanged: it only negates the angle of every later dressed rotation it anticommutes with, and the sign of the dressed observable if it anticommutes with that too. A noisy expectation value is then an average of noiseless HSMPO expectation values over sign patterns of the rotation chain: the patterns with zero and one fault are summed exactly, those with two or more are sampled. Coherent errors are dressed like magic gates and join the chain.

A general channel, written in the Pauli basis as sum_{A, B} chi[A, B] A rho B, splits into its diagonal, a Pauli channel handled as above, and its off-diagonal coherences, which make it non-unital. A coherence acts on the ket with A and on the bra with B: it flips the two chains’ signs differently and contributes the transition amplitude between them, weighted by the complex chi[A, B]. The one-location terms stay exact; with several locations the sampled weights become a quasi-probability, whose total exceeds 1 by about the summed |chi| of the coherences.

Readout noise flips a measured 0 with probability p0 and a 1 with probability p1: every non-identity factor of a Pauli term on that qubit becomes (1 - p0 - p1) P + (p1 - p0) I.

Usage Example:

from qibo import gates
from mpstab import (
    HSMPO,
    CoherentError,
    DepolarizingError,
    NoiseModel,
    PauliError,
    ReadoutError,
    StatePreparationError,
    ThermalRelaxationError,
)
from mpstab.models.ansatze import KickedIsing

ansatz = KickedIsing(nqubits=4, n_steps=1, theta_h=0.7, theta_z=0.3)
surrogate = HSMPO(ansatz)

noise = NoiseModel()
noise.add(PauliError({"X": 1e-3, "Y": 1e-3, "Z": 1e-3}))  # every gate, every qubit
noise.add(DepolarizingError(0.01), gates.CNOT)           # two-qubit depolarizing
noise.add(PauliError({"ZZ": 0.005}), gates.CNOT)         # correlated dephasing
noise.add(CoherentError("ZZ", 0.02), gates.CNOT)         # residual coupling
noise.add(ThermalRelaxationError(t1=100.0, t2=80.0, time=0.05), gates.CNOT)

chain = [(0, 1), (1, 2), (2, 3)]
noise.add_crosstalk(CoherentError("ZZ", 0.01), chain, gates.CNOT)
noise.add_idle(ThermalRelaxationError(t1=100.0, t2=80.0, time=0.02))
noise.add_idle(CoherentError("ZZ", 0.005).twirled(), coupling=chain)

noise.add(StatePreparationError(0.005))                  # |0> prepared as |1>
noise.add(ReadoutError(0.01, 0.03))                      # 1 -> 0 likelier

result = surrogate.noisy_expectation("ZIIZ", noise, n_samples=500, seed=0)
print(f"noiseless {surrogate.expectation('ZIIZ'):+.4f}")
print(f"noisy     {result.mean:+.4f} +- {result.stderr:.4f}")

# Noise-strength sweeps, e.g. for zero-noise extrapolation:
stronger = noise.scaled(2.0)

A gate-attached noise model, built with NoiseModel.add() as in qibo.

class mpstab.models.noise.model.CoherentError(generator: str, angle: float)[source]¶

Coherent error exp(-i angle/2 P), such as an over-rotation or a residual ZZ coupling.

A single-qubit generator acts on each qubit of the gate; one as wide as the gate acts jointly on its qubits, in the gate’s qubit order. class mpstab.models.noise.model.KrausError(operators: Sequence[ndarray])[source]¶

Any channel, given by its Kraus operators: rho -> sum_k K_k rho K_k^dag.

])
class mpstab.models.noise.model.NoiseModel(rules: list[_Rule] = <factory>)[source]¶

Noise attached to a circuit, built rule by rule as in qibo.

  • add() puts an error right after each matching gate, or, for ReadoutError and StatePreparationError, on the measured bits and on the initial state.

  • add_crosstalk() puts it on the spectators of each matching gate: the qubits coupled to the gate but not acted on by it.

  • add_idle() puts it on the qubits left idle in each moment of the circuit.

Pass the model to noisy_expectation(); apply() gives the same noisy circuit as a qibo density-matrix circuit, for exact reference values.

Variables:

rules (list[mpstab.models.noise.model._Rule]) – the rules added so far, in order.

Example:

from qibo import gates

    HSMPO,
    AmplitudeDampingError,
    CoherentError,
    DepolarizingError,
    NoiseModel,
    PauliError,
)
from mpstab.models.ansatze import KickedIsing

chain = [(0, 1), (1, 2), (2, 3)]
noise = NoiseModel()

noise.add(PauliError({"ZZ": 5e-4}), gates.CNOT)        # correlated, on CNOTs

Put error on the qubits left idle in each moment of the circuit.

Moments are an in-order layering of the gate queue: a gate lands one moment after the last gate on any of its qubits, and never before the gate queued ahead of it, so a circuit queued layer by layer gets its layers as moments. A single-qubit error acts on every idle qubit of every moment, before its first gate and after its last one included. A two-qubit error, such as an always-on ZZ coupling, acts on each coupling edge whose two qubits are both idle.

Parameters:

  • error – the error, on one qubit or on two.

  • qubits – restrict the error to these qubits.

  • coupling – the coupling graph, needed by two-qubit errors.

Returns:

self, so calls can be chained.

class mpstab.models.noise.model.ReadoutError(p0: float, p1: float | None = None)[source]¶

Readout bit flips: a measured 0 is reported as 1 with probability p0, and a 1 as 0 with probability p1 (p0 if not given).

A Pauli expectation value is estimated from the bits read out in the term’s eigenbasis, so every non-identity factor P of a term on a noisy qubit becomes (1 - p0 - p1) P + (p1 - p0) I. A symmetric error only attenuates the term; an asymmetric one also mixes in its lower-weight subterms. Add it with no gate, optionally restricted to some qubits; errors on the same qubit compose.

Variables:

  • p0 (float) – probability of reading a 0 as 1, in [0, 1].

  • p1 (float | None) – probability of reading a 1 as 0, in [0, 1]; p0 if not given.

Example:

from mpstab import NoiseModel, ReadoutError

noise = NoiseModel()
noise.add(ReadoutError(0.02))                    # every qubit
noise.add(ReadoutError(0.01, 0.05), qubits=[0])  # 1 -> 0 is likelier

class mpstab.models.noise.model.ThermalRelaxationError(t1: float, t2: float, time: float, excited_population: float = 0.0)[source]¶

Thermal relaxation for a duration time on each qubit of the gate: the excited population relaxes to excited_population with time constant t1, and coherences decay as exp(-time / t2).

It is generalized amplitude damping with gamma = 1 - exp(-time / t1) followed by the pure dephasing that brings the coherence decay from exp(-time / (2 t1)) down to exp(-time / t2), so t2 <= 2 t1. scaled() scales time.

Variables:

  • t1 (float) – energy relaxation time.

  • t2 (float) – dephasing time, at most 2 * t1.

  • time (float) – duration of the error, in the units of t1 and t2.

  • excited_population (float) – equilibrium population of |1>, in [0, 1].

Example:

from mpstab import ThermalRelaxationError

idle = ThermalRelaxationError(t1=100e-6, t2=80e-6, time=50e-9)

Low-level interface¶

noisy_expectation() resolves the model into noise events placed by gate index, compiles them into the Clifford frame and runs the fault-pattern estimator. The three steps are available on their own.

Noise events: what happens, and after which gate of the circuit.

Every event is anchored to a position in ansatz.circuit.queue: it acts right after the gate at index after_gate, or on the initial state when after_gate is -1. Events sharing an anchor act in the order they are listed.

class mpstab.models.noise.events.KrausChannel(after_gate: int, qubits: tuple[int, ...], kraus: tuple[ndarray, ...])[source]¶

Bases: NoiseEvent

A general channel rho -> sum_k K_k rho K_k^dag on a few qubits, such as amplitude damping or thermal relaxation.

In the Pauli basis the channel is sum_{A, B} chi[A, B] A rho B (chi). The diagonal of chi is a Pauli channel, its Pauli twirl; the off-diagonal entries are what makes it non-unital or otherwise non-Pauli, and the estimator evaluates them as transition amplitudes between two sign patterns of the rotation chain.

Variables:

  • after_gate (int) – index of the gate the channel follows, or -1 for the initial state.

  • qubits (tuple[int, ...]) – the qubits the channel acts on. qubits[0] is the most significant factor of the Kraus matrices, as in qibo.

  • kraus (tuple[numpy.ndarray, ...]) – Kraus operators, each 2**k x 2**k for k = len(qubits). They must satisfy sum_k K_k^dag K_k = I.

Example:

# Amplitude damping of qubit 0 after the first gate.
import numpy as np
from mpstab.models.noise.events import KrausChannel

gamma = 0.05
damping = KrausChannel(
    after_gate=0,
    qubits=(0,),
    kraus=(
        np.array([[1, 0], [0, np.sqrt(1 - gamma)]]),
        np.array([[0, np.sqrt(gamma)], [0, 0]]),
    ),
)
print(damping.chi[("I", "Z")])  # gamma / 4

The process matrix in the Pauli basis, {(A, B): chi[A, B]}, with A and B labels on qubits; entries below 1e-15 in magnitude are left out. It is Hermitian, and its diagonal sums to 1.

Pull noise events into the Clifford frame of an HSMPO surrogate.

A Pauli fault E after Clifford prefix C is the dressed fault E' = C^dag E C at the same point of the dressed-rotation chain. Moving it through every later dressed rotation and the Clifford remainder to the observable leaves the tableau untouched: it only flips the sign of the angle of each later rotation whose generator anticommutes with E', and the sign of the dressed observable if that anticommutes too. A coherent rotation is dressed exactly like a magic gate and joins the chain.

A general channel sum_{A, B} chi[A, B] A rho B splits into its diagonal, a Pauli channel compiled as above, and pairs (A, B) of its off-diagonal entries, the coherences. A coherence acts on the ket with A' and on the bra with B', so it flips the ket’s and the bra’s rotation signs differently and contributes a transition amplitude between the two.

A noisy circuit in the Clifford frame of an HSMPO surrogate.

Build it with compile_noise(). Each location is one PauliChannel or KrausChannel. Each fault is a non-identity Pauli of a location with nonzero probability: a term of the Pauli channel, or a diagonal entry of the Kraus channel’s process matrix. restricted_to(dressed_paulis: Sequence[str]) → CompiledNoise[source]¶

The same noisy circuit, reduced to what can affect an observable.

Rotations outside the observable’s light cone (pauli_light_cone()) are dropped. A fault that then flips no remaining rotation and commutes with the observable terms leaves every expectation value unchanged, so it is folded into its location’s no-fault probability, and locations left with nothing are dropped.

A location with coherences is dropped whole when all its Paulis pass the same test: the channel then commutes through to the observable, where trace preservation makes it the identity. Otherwise its Paulis spread the observable, so they join the light cone, which may keep more rotations and locations; this is repeated until nothing changes. Every step is exact for this observable.

Parameters:

dressed_paulis – dressed observable terms, from dress_observable().

Returns:

A new CompiledNoise; this one is left untouched.

mpstab.models.noise.compile.compile_noise(hsmpo: HSMPO, events: Sequence[NoiseEvent]) → CompiledNoise[source]¶

Dress the noise events of a circuit with its Clifford frame.

The stabilizers engine dresses every magic gate, coherent rotation and Pauli fault with the Clifford gates before its own position, in one call (backpropagate_at()), and the flip matrix then follows from the symplectic form in one matrix product.

Parameters:

  • hsmpo – surrogate of the noiseless circuit. Its ansatz.circuit.queue is what after_gate indexes. It may be built with rotations_only().

  • events – the noise, as PauliChannel, CoherentRotation and KrausChannel events.

Returns:

The CompiledNoise.

Raises:

  • NotImplementedError – on an event type this function does not know.

  • ValueError – on an after_gate outside the circuit, or an ansatz whose own partitioning does not follow its circuit queue (FloquetAnsatz).

Example:

from qibo import Circuit, gates
from mpstab import HSMPO
from mpstab.models.noise.compile import compile_noise
from mpstab.models.noise.events import PauliChannel

circuit = Circuit(2)
circuit.add(gates.H(0))
circuit.add(gates.RZ(0, theta=0.3))
circuit.add(gates.CNOT(0, 1))
# A bit flip between the H and the RZ anticommutes with the RZ.
events = [PauliChannel(after_gate=0, qubits=(0,), probs={"X": 0.01})]
compiled = compile_noise(HSMPO(circuit), events)
print(compiled.generators, compiled.flips)  # ['XI'] [[ True]]

Noisy expectation values as averages over sign patterns of the rotation chain.

Every set of faults maps to a sign pattern over the dressed rotations and the observable terms (mpstab.models.noise.compile), so the noisy expectation value of Pauli noise is a probability-weighted average of noiseless HSMPO expectation values with some angles negated. A coherence (A, B) of a non-Pauli channel flips the ket’s and the bra’s angles differently, and contributes the transition amplitude <phi_B| B' O A' |phi_A> between the two patterns with the complex weight chi[A, B].

The sum over configurations is stratified by the number k of locations that do something, each configuration weighted by the product of its entries: the no-fault probability, a fault’s probability or a coherence’s complex weight.

  • k = 0 and k = 1 are summed exactly;

  • k >= 2 is sampled from its conditional distribution, with coherences drawn by |chi| and their phases carried as a weight, and its mean is multiplied by the total weight of that stratum.

For Pauli noise the weights are probabilities. Coherences make them a quasi-probability, whose total exceeds 1 by about their summed |chi|.

Before any of this, the circuit is restricted to the light cone of the observable and the coherences (restricted_to()): rotations that cannot affect them are dropped, and so are faults that then do nothing. Patterns are deduplicated, then evaluated in lexicographic order, each one restarting from the MPS checkpoint before its first rotation that differs from the previous pattern; the bra of a transition branches off the ket’s checkpoint at their first difference.

mpstab.models.noise.mc_noise_estimator.noisy_expectation(compiled: CompiledNoise, observable: str | list | dict | SymbolicHamiltonian, n_samples: int = 1000, seed: int | None = None, light_cone: bool = True, n_workers: int = 1) → NoisyExpectation[source]¶

Expectation value of observable on the noisy circuit.

Parameters:

  • compiled – the noisy circuit, from compile_noise().

  • observable – a Pauli string or any other format pauli_terms() accepts.

  • n_samples – configurations to sample for the k >= 2 stratum. With 0 that stratum is dropped, which biases the mean by at most stratum_weights[2] times the sum of the absolute coefficients.

  • seed – seed of the sampler.

  • light_cone – restrict the circuit to the observable’s light cone first. This is exact, and it leaves fewer rotations per pattern and fewer faults, so a smaller k >= 2 weight and a smaller standard error. Turn it off only to compare against the unrestricted computation.

  • n_workers – processes evaluating the sign patterns of Pauli faults. The distinct patterns are split into contiguous blocks, so the result is identical for any value; each extra process costs a start-up of about a second, so it pays off only when there are many patterns or the MPS is large. Transition amplitudes are evaluated in this process.

Returns:

The NoisyExpectation.

Example:

from qibo import Circuit, gates
from mpstab import HSMPO
from mpstab.models.noise.compile import compile_noise
from mpstab.models.noise.mc_noise_estimator import noisy_expectation
from mpstab.models.noise.events import PauliChannel

circuit = Circuit(2)
circuit.add(gates.RY(0, theta=0.4))
circuit.add(gates.CNOT(0, 1))
events = [
    PauliChannel(after_gate=g, qubits=(0, 1), probs={"XX": 0.02, "ZI": 0.01})
    for g in range(2)
]
compiled = compile_noise(HSMPO(circuit), events)
result = noisy_expectation(compiled, "ZZ", n_samples=200, seed=0)
print(f"{result.mean:.4f} +- {result.stderr:.4f}")
