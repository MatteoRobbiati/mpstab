Error Mitigation¶

Clifford data regression (CDR) learns a map from noisy expectation values to noiseless ones on training circuits close to the target, then applies it to the target’s noisy value. The training circuits are low-magic variants of the target, in which each non-Clifford gate is replaced by a Clifford one with some probability. HSMPO computes their noiseless values cheaply, even with the leftover magic that keeps them close to the target.

  • cdr() fits exact = a * noisy + b;

  • vncdr() (variable-noise CDR) fits the exact value as a linear combination of the noisy values at several noise levels.

Both return a MitigationNoiseMap, which holds the fitted parameters and the training data, and is called on the target’s noisy value(s) to mitigate them.

The noisy values come from noise: a NoiseModel, simulated with noisy_expectation(), or any callable returning the noisy value of a circuit, such as one running it on hardware. For vnCDR a noise model is amplified either by scaling every error’s strength (amplification="scale") or by global unitary folding (amplification="fold", fold_circuit()).

Example¶

import numpy as np
from qibo import gates

from mpstab import HSMPO
from mpstab.models.ansatze import HardwareEfficient
from mpstab.models.error_mitigation import cdr, noisy_value, vncdr
from mpstab.models.noise import DepolarizingError, NoiseModel, PauliError

ansatz = HardwareEfficient(nqubits=4, nlayers=2)
ansatz.circuit.set_parameters(
    np.random.default_rng(1).uniform(-np.pi, np.pi, ansatz.nparams)
)
noise = (
    NoiseModel()
    .add(DepolarizingError(0.01))
    .add(PauliError({"ZZ": 0.01}), gates.CZ)
)

target = HSMPO(ansatz)
noisy = noisy_value(target, "ZZII", noise, seed=0)

noise_map = cdr(ansatz, "ZZII", noise, n_training_circuits=30,
                replacement_probability=0.7, seed=0)
print(target.expectation("ZZII"), noisy, noise_map(noisy))

levels = (1, 3, 5)
noise_map = vncdr(ansatz, "ZZII", noise, noise_levels=levels,
                  n_training_circuits=30, replacement_probability=0.7, seed=0)
print(noise_map([noisy_value(target, "ZZII", noise, l, seed=0) for l in levels]))

On hardware, pass the executor instead of the noise model, and mitigate the value measured on the target circuit (run_on_qpu stands for your own execution code):

noise_map = cdr(ansatz, "ZZII", lambda circuit: run_on_qpu(circuit, "ZZII"))
mitigated = noise_map(run_on_qpu(ansatz.circuit, "ZZII"))

Mitigating an HQSMPO measurement plan¶

On hardware, HQSMPO measures a head circuit under many measurement settings. VnCDRMitigation plans the extra circuits that mitigate all of them at once: the head folded to several noise levels, low-magic training variants of it measured in their most informative settings, and six circuits calibrating the measurement layer. One vnCDR map, fitted on every training measurement, corrects every setting (ansatz, hamiltonian and noise stand for your own):

from mpstab import HQSMPO
from mpstab.models.error_mitigation import VnCDRMitigation
from mpstab.qpu import NoisySimulator, execute_plan

model = HQSMPO(ansatz, head_synthesis="extraction")
mitigation = VnCDRMitigation(n_training_circuits=8, training_settings=3)
plan = mitigation.build_plan(model, hamiltonian, cut_index, n_shots=50_000, seed=0)

counts = execute_plan(NoisySimulator(noise), plan)  # or run plan.circuits on a device
result = plan.estimate(counts)
print(result.unmitigated, result.measurement_mitigated, result.value)

API¶

Error mitigation of an HQSMPO measurement plan with variable-noise CDR.

An HQSMPO plan runs one head circuit under many measurement settings, each measuring a group of Pauli strings of the folded observable O = sum_P c_P P. Its noise splits in two:

  • the gates of the head, the same for every circuit of the plan, mitigated with variable-noise Clifford data regression (vnCDR);

  • the measurement layer, basis rotations and readout, which changes with the setting, calibrated once for every Pauli string at a low overhead.

One map, fitted and applied per setting. The training circuits are low-magic variants of the head. HSMPO gives the noiseless value of every setting of a training circuit, so each training measurement, one circuit in one setting at every noise level, is a data point of its own: one vnCDR map is fitted on all of them and applied to every setting of the target. Fitting the map on whole-observable values instead would fail whenever terms of opposite sign partly cancel the noise in the sum.

Choosing the data. Training is cheap when the data are informative:

  • circuits: a pool of candidates is sampled and the training set picked to spread its noiseless values evenly, since clustered values carry little information on the map (Czarnik et al., arXiv:2204.07109);

  • settings: each training circuit can measure only a few settings, drawn by the size of their noiseless contribution to it. A setting worth nothing on a training circuit says nothing about the map.

The measurement layer is calibrated by preparing both eigenstates of the X, Y and Z bases on every qubit and measuring them in the same basis, six circuits in all. A noisy measurement of qubit q in basis B reads z' = c z + a on average, with an attenuation c and, for an asymmetric readout, an offset a, both read off the two eigenstates. On estimation each factor z'_q of a shot’s parity becomes (z'_q - a_q) / c_q, which undoes the measurement noise exactly when it acts on each qubit independently.

Clifford data regression (CDR) and its variable-noise extension (vnCDR).

Both learn a map from noisy expectation values to noiseless ones on training circuits close to the target, then apply it to the target’s noisy value:

  • the training circuits are low-magic variants of the target (training_circuits());

  • their noiseless values come from HSMPO, cheap because they carry little magic;

  • their noisy values come either from a NoiseModel, simulated by noisy_expectation(), or from any callable, such as one running the circuit on hardware.

References

  1. P. Czarnik, A. Arrasmith et al., Error mitigation with Clifford quantum-circuit data, arXiv:2005.10189.

  2. A. Lowe, M. H. Gordon et al., Unified approach to data-driven quantum error mitigation, arXiv:2011.01157.

Learn the variable-noise CDR noise map of observable on ansatz.

The map takes the target’s noisy values at every level of noise_levels, so evaluate the target the same way. For a noise model, noisy_value() does it:

levels = (1, 3, 5)
noise_map = vncdr(ansatz, "ZZII", noise, noise_levels=levels, seed=0)
target = HSMPO(ansatz)
mitigated = noise_map(
    [noisy_value(target, "ZZII", noise, level) for level in levels]
)
Parameters:

  • ansatz – the circuit to mitigate.

  • observable – a Pauli string or any other format pauli_terms() accepts.

  • noise – a NoiseModel, simulated with HSMPO, or a callable f(circuit, level) -> float giving the noisy value of a circuit at a noise level, for instance by running fold_circuit() of it on hardware. The circuit it receives starts with initial_state, if any.

  • noise_levels – the noise amplification factors, 1 being the unamplified noise.

  • amplification – how a noise model is amplified: "scale" multiplies every error’s strength by the level (scaled()), "fold" runs the folded circuit (fold_circuit()), which needs odd integer levels. Ignored for a callable.

  • n_training_circuits – training circuits to sample.

  • replacement_probability – chance of replacing each non-Clifford gate in a training circuit (training_circuits()).

  • replacement_method – "closest" or "random" Clifford angle.

  • model – model(x, *params) to fit, with x an array whose last axis runs over the noise levels. The default x @ params, a linear combination of the levels as in [2], is fitted by least squares; any other with scipy.optimize.curve_fit, starting from ones.

  • initial_state – one-qubit-gates-only circuit preparing the initial state, |0...0> if None.

  • max_bond_dimension – MPS truncation cap for HSMPO.

  • n_samples – fault configurations HSMPO samples per noisy value, when noise is a noise model.

  • seed – seed of the training circuits and of the noise sampling.

  • n_workers – processes evaluating the training circuits in parallel, when noise is a noise model; a callable always runs in this process. The result does not depend on it.

MitigationNoiseMap, with noise_levels set.

Training circuits for Clifford data regression, and noise amplification.

mpstab.models.error_mitigation.training.fold_circuit(circuit: Circuit, level: int) → Circuit[source]¶

Amplify the noise of circuit by global unitary folding.

Returns \(U (U^\dagger U)^k\) with level = 2k + 1: the same unitary, with level times as many gates, hence about level times the noise. Measurement gates are dropped.

Parameters:

  • circuit – the circuit \(U\) to fold.

  • level – the noise level, an odd positive integer. 1 returns a copy.

Raises:

ValueError – if level is not an odd positive integer.

mpstab.models.error_mitigation.training.training_circuits(ansatz: Ansatz | Circuit, n_circuits: int, replacement_probability: float = 0.9, replacement_method: str = 'closest', seed: int | None = None) → list[Circuit][source]¶

Low-magic variants of ansatz to train a CDR noise map on.

Each non-Clifford gate is replaced by a Clifford one with probability replacement_probability and kept otherwise (partitionate_circuit()). Unlike the fully Clifford circuits of the original CDR, the gates that are kept leave some magic in each circuit, which HSMPO still simulates cheaply, so the training set stays closer to the target circuit. Every circuit keeps the target’s gate sequence, only with other angles, so noise placed by gate type or position acts on it as on the target.

Parameters:

  • ansatz – the circuit to mitigate.

  • n_circuits – training circuits to sample.

  • replacement_probability – chance of replacing each non-Clifford gate. Lower values keep more magic: closer to the target, costlier to simulate.

  • replacement_method – "closest" or "random" Clifford angle.

  • seed – seed of the replacement draws.

Returns:

The sampled circuits, as qibo Circuit objects.
